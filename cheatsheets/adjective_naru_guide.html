Adjective + なる

なる (naru) — "to become" · indicating change
Grammar · Beginner–Intermediate

What is なる?

Concept
Key Rule

The verb なる (naru) means "to become," and indicates a change of state. It follows nouns and both types of adjectives, but the connector differs depending on the word type.

Formation Patterns

Pattern
い-adj: drop い → stem + く + なる e.g. あたたかい → あたたかくなる
な-adj: drop な → stem + に + なる e.g. 静かな → 静かになる
Noun → Noun + に + なる e.g. 学生になる

Common Mistake

With い-adjectives, the connector is く, not に. Do not copy the な-adj / noun pattern.
あたたかいになる ✗  →  あたたかくなる ✓

Absolute vs. Relative Change

Usage Note
Ambiguity

When an adjective is used with なる, the sentence can describe either an absolute change (e.g. "It has become warm — it is no longer cold") or a relative change (e.g. "It has become warmer, but it is still cold"). なる sentences are ambiguous in isolation.

Making relative change explicit

To make clear that you are talking in relative terms, add the comparison pattern using より (yori) — "than" — together with なる.

Example 4 — Relative change with より + なりました
"Mary has become better in Japanese than before."
メアリー Mary
は wa
前(まえ)より maeyori
日本語 nihongo
が ga

なりました。 narimashita.
より (yori) = "than" · marks comparison baseline な-adj (上手な → 上手に) なる · past affirmative
