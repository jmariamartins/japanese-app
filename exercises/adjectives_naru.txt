# TOPIC: Adjectives + なる — Becoming / Changing State
# LEVEL: beginner

# ─────────────────────────────────────────
# Structure — changing an adjective into "become [adj]":
#   i-adjective:  drop い → add く + なる
#     e.g. たかい → たかく なる = become tall / get taller
#   na-adjective: drop な → add に + なる
#     e.g. じょうずな → じょうずに なる = become good at
#   noun:         noun + に + なる
#     e.g. けいさつかん に なる = become a police officer
# Past: なる → なりました / なった
# Want to become: なりたい / なりたかった
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I intend to clean up because my room got dirty.
ROM: Watashi no heya wa kitanaku natta kara, souji suru tsumori desu.
JP: わたし の へや は きたなく なった から、そうじする つもりです。
HINT: きたない (kitanai, i-adj) → drop い → きたなく (kitanaku) + なった (natta, past short) · から (kara) = because

DIR: EN>JP
Q: My daughter became 9 years old and got taller.
ROM: Watashi no musume wa 9-sai ni natte, se ga takaku narimashita.
JP: わたし の むすめ は ９さい に なって、せ が たかく なりました。
HINT: age uses に (ni) なる (naru) · i-adj: たかい (takai) → たかく (takaku) なりました (narimashita) · two changes linked with て-form
