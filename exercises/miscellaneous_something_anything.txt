# TOPIC: Miscellaneous — Something, Anything, Somewhere, Someone
# LEVEL: beginner

# ─────────────────────────────────────────
# Pattern:
#   question word + か (ka) = some~ (affirmative context)
#     どこか (dokoka) = somewhere, なにか (nanika) = something, だれか (dareka) = someone
#   question word + にも (ni mo) + negative = no~ / not any~
#     どこにも (doko ni mo) + neg = nowhere / not anywhere
#     だれにも (dare ni mo) + neg = no one / not anyone
#   Plain question words in questions (no か or も added)
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: Did you go anywhere yesterday?
ROM: Kinou doko ka ni ikimashita ka?
JP: きのう どこかに いきました か？
HINT: "anywhere" in a question = どこか (dokoka) + に (ni) · not plain どこ (doko), that asks "where exactly?"

---
DIR: EN>JP
Q: I did not go anywhere yesterday.
ROM: Kinou doko ni mo ikimasen deshita.
JP: きのう どこにも いきませんでした。
HINT: "nowhere / not anywhere" = どこにも (doko ni mo) + negative verb · にも (ni mo) replaces に (ni)
