# TOPIC: Guess and Prediction (〜でしょう)
# LEVEL: beginner

# ─────────────────────────────────────────
# でしょう (deshou) = probably / I think… / I suppose…
#   Expresses conjecture — the speaker's best guess.
# Structure:
#   noun/na-adj: [plain form] + でしょう
#   i-adjective: [short form] + でしょう
#   verb: [short/dictionary form] + でしょう
# Negative: [negative short form] + でしょう
# Question: でしょうか？ = Do you think…? / I wonder if…?
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: Maki is probably 23 years old.
ROM: Maki wa 23-sai deshou.
JP: まき は ２３さい でしょう。
HINT: noun + でしょう (deshou) · no だ (da) before でしょう

DIR: EN>JP
Q: Masato is probably not famous.
ROM: Masato wa yuumei ja nai deshou.

HINT: na-adj negative: ゆうめいじゃない (yuumei ja nai) + でしょう (deshou) · negative conjecture

HINT: うたう (utau) のが (no ga) すき (suki) = likes singing (nominalised verb) · すき + でしょう (deshou)
