# TOPIC: Potential Form — Can / Cannot (〜られます / 〜られません)
# LEVEL: intermediate
# SOURCE: NHK World Easy Japanese (Lesson 24)

# ─────────────────────────────────────────
# Conjugation rules:
#   ru-verbs: drop る → add られる
#     食べる → 食べられる → 食べられます / 食べられません
#   u-verbs: change final sound to e-row + る
#     飲む → 飲める → 飲めます / 飲めません
#     行く → 行ける, 話す → 話せる, 乗る → 乗れる
#   Irregulars: する → できる / くる → こられる
# Note: NHK Lesson 24 focuses on food/dietary restrictions
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I can't eat raw eggs.
ROM: Nama tamago wa taberaremasen.
JP: なまたまごは たべられません。
HINT: taberu (ru-verb) → taberareru (potential) → taberaremasen (neg. polite) · NHK Lesson 24 key phrase · なまたまご (nama tamago) = raw egg

DIR: EN>JP
Q: I'm sorry. I can't eat raw fish.
ROM: Sumimasen. Watashi, sashimi wa taberaremasen.
JP: すみません。わたし、さしみは たべられません。
HINT: same taberu → taberaremasen pattern · NHK Lesson 24 Use It! example · さしみ (sashimi) = raw fish
