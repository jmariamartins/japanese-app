# TOPIC: I Want (Thing) — ほしい / ほしがる
# LEVEL: intermediate

# ─────────────────────────────────────────
# Structure:
#   [object] が ほしいです           = I want [object]
#   [object] は/が ほしくないです    = I don't want [object]
#   ほしい conjugates like an い-adjective:
#     ほしいです / ほしくありません / ほしかったです / ほしくありませんでした
# ほしい is a "private predicate": normally first person only.
# For other people:
#   Quotation:   [person] は [object] が ほしい と言っています
#   Guess:       [person] は [object] が ほしくない でしょう
#   Observation: [person] は [object] を ほしがっています  (note を, not が)
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I want a good kanji dictionary.
ROM: Ii kanji no jisho ga hoshii desu.
JP: いい 漢字の 辞書が ほしいです。
HINT: [object] が ほしいです = I want [object] · ほしい (hoshii) = want (a thing) · じしょ (jisho) = dictionary · かんじ (kanji) = kanji

ROM: Gojira no omocha ga hoshikatta desu.
JP: ゴジラの おもちゃが ほしかったです。
HINT: past affirmative: ほしかったです (hoshikatta desu) · おもちゃ (omocha) = toy · ゴジラ (Gojira) = Godzilla

DIR: EN>JP
Q: I don't have much desire for money.
ROM: Okane wa amari hoshiku arimasen.
JP: お金は あまり ほしくありません。
HINT: present negative: ほしくありません (hoshiku arimasen) · あまり (amari) + negative = not much · おかね (okane) = money · は (wa) marks the unwanted object

DIR: EN>JP
Q: Robert says he wants a laptop.
ROM: Robaato wa pasokon ga hoshii to itte imasu.
JP: ロバートは パソコンが ほしいと 言っています。
HINT: quote someone's own words: ほしい (hoshii) + と いっています (to itte imasu) = says that… · パソコン (pasokon) = computer / laptop
