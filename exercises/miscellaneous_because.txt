# TOPIC: Miscellaneous — Because (〜ので / 〜から)
# LEVEL: beginner

# ─────────────────────────────────────────
# Two ways to say "because":
#   〜ので (node) = softer, more objective · preferred in polite/written contexts
#   〜から (kara) = more direct/assertive · more common in casual speech
# Word order:
#   [reason] ので/から、[result]   ← reason first (most common)
#   [result]。[reason] から。      ← result first, reason appended (casual)
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I did not study yesterday because I did not have homework.
ROM: Shukudai ga nakatta node, watashi wa kinou benkyou shimasen deshita.
JP: しゅくだい が なかった ので、わたし は きのう べんきょうしませんでした。
HINT: ので (node) comes after SHORT FORM (nakatta) · reason first, then result
