# TOPIC: Miscellaneous — Too… (〜すぎます)
# LEVEL: beginner

# ─────────────────────────────────────────
# Structure — "too [adjective/verb]":
#   i-adjective: drop い → add すぎます
#     e.g. さむい → さむすぎます (too cold)
#   na-adjective: drop な → add すぎます
#   verb: use STEM (masu-form minus ます) → add すぎます
# Past: すぎます → すぎました
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: This coffee is too bitter.
ROM: Kono ko-hi- wa niga sugimasu.
JP: この こーひー は にが すぎます。
HINT: にがい (nigai, bitter, i-adj) → drop い (i) → にが + すぎます (sugimasu)
