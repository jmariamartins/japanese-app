# TOPIC: Miscellaneous — Physical Description
# LEVEL: beginner

# ─────────────────────────────────────────
# Structure: [subject] は [body part] が [adjective] です。
#   = Subject has a [adj] [body part]
# Key body parts: せ (se, height), かみ (kami, hair), あたま (atama, head/brain),
#   くび (kubi, neck), くち (kuchi, mouth), はな (hana, nose)
# Note: あたまがいい = smart (lit. "head is good") — NOT about head size
# ─────────────────────────────────────────

---
DIR: JP>EN
Q_ROM: Takumi wa se ga hikui desu.
Q_JP: たくみ は せ が ひくいです。
A: Takumi is short.
HINT: せ (se) = height · ひくい (hikui) = low/short (for height) · not みじかい (mijikai), that's for length of objects

---
DIR: JP>EN
Q_ROM: Yuuto wa se ga takai desu.
Q_JP: ゆうと は せ が たかいです。
A: Yuuto is tall.
HINT: せがたかい (se ga takai) = tall (lit. "height is high") · たかい (takai) = high/tall

---
DIR: JP>EN

HINT: かみ (kami) = hair · みじかい (mijikai) = short (for objects/lengths, not height)
