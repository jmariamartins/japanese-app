# TOPIC: Te-form — Trying Something (〜てみる)
# LEVEL: intermediate
# SOURCE: NHK World Easy Japanese (Lessons 13, 14)

# ─────────────────────────────────────────
# Structures covered:
#   [verb-te] + みます           = I'll try doing... (present/future)
#   [verb-te] + みたいです       = I want to try doing...
#   [verb-te] + みました         = I tried doing... (past)
#   [verb-te] + みませんでした   = I didn't try doing... (past negative)
# Key rule: て-form of verb + みる (to see/try) = to try doing
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I want to try going to Japan.
ROM: Nihon e itte mitai desu.
JP: にほんへ いってみたいです。
HINT: iku → itte (te-form) + みたいです (mitai desu) · NHK Lesson 13 key phrase · へ (e) = destination direction

ROM: Fujisan ni nobotte mitai desu.
JP: ふじさんに のぼってみたいです。
HINT: noboru → nobotte (te-form) + みたいです · に (ni) = destination · NHK Lesson 13 model answer

---
DIR: EN>JP
Q: I'll try eating it.
ROM: Tabete mimasu.
JP: たべてみます。
HINT: taberu → tabete + みます (mimasu, present/future) · てみます = will try doing · less commitment than てみたいです

---
DIR: EN>JP
Q: I'll try speaking in Japanese.
ROM: Nihongo de hanashite mimasu.
JP: にほんごで はなしてみます。
HINT: hanasu → hanashite (te-form) + みます · で (de) = medium/method (in Japanese)

---
DIR: EN>JP

HINT: tabete + みました (mimashita, past) = tried eating · past tense is in みました, not the te-form
