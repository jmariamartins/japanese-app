# TOPIC: Miscellaneous — Implicit Explanation (〜んです)
# LEVEL: beginner

# ─────────────────────────────────────────
# んです (n desu) / のです (no desu) adds an explanatory nuance:
#   "The thing is…" / "You see, I…"
# Structure:
#   i-adjective short form + んです  (e.g. いたいんです, itai n desu)
#   verb short form + んです         (e.g. みたんです, mita n desu)
#   verb stem + たいんです           (e.g. たべたいんです, tabetai n desu)
#   na-adjective: だ → な + んです   (e.g. たいへんなんです, taihen na n desu)
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I have a stomachache. (explaining to someone)
ROM: Onaka ga itai n desu.
JP: おなか が いたい んです。
HINT: いたい (itai) = i-adjective (hurts/aches) · + んです (n desu) gives the "I'm explaining" nuance · おなか (onaka) = stomach

HINT: わかれる (wakareru) → past short: わかれた (wakareta) + んです (n desu) · と (to) = with (the person)
