# TOPIC: Comparison — より / のほうが / いちばん
# LEVEL: beginner

# ─────────────────────────────────────────
# Three comparison structures:
#   A のほうが B より [adj]  = A is more [adj] than B
#   A と B と どっち のほうが [adj] ですか？ = Between A and B, which is more [adj]?
#   〜の なかで どれ/どこ/だれ が いちばん [adj]？ = Among ~, which/where/who is the most [adj]?
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: Tomoka is taller than Maki.
ROM: Tomoka no hou ga Maki yori se ga takai desu.
JP: ともか のほうが まき より せ が たかいです。
HINT: A のほうが (no hou ga) B より (yori) [adj] · せがたかい (se ga takai) = tall (lit. "height is high") · A comes first

HINT: comparing two things: A と (to) B と どっち (dotchi) のほうが…？ · すき (suki) = like (na-adjective)
