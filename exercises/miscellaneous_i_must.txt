# TOPIC: Miscellaneous — I Must… (〜なくちゃいけません)
# LEVEL: beginner

# ─────────────────────────────────────────
# Structure:
#   [verb negative short] → drop the final い → add くちゃいけません (kucha ikemasen)
#   e.g. たべない (tabenai) → たべな + くちゃいけません = must eat
#        いかない (ikanai) → いかな + くちゃいけません = must go
# This is the contracted/casual form of 〜なければなりません (nakereba narimasen).
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I must clean the room tomorrow.
ROM: Ashita heya wo souji shinakucha ikemasen.
JP: あした へや を そうじしなくちゃいけません。
HINT: そうじする (souji suru) → negative: しない (shinai) → drop い → しな + くちゃいけません (kucha ikemasen) · を (wo) = object

HINT: およぐ (oyogu) → negative: およがない (oyoganai) → drop い → およがな + くちゃいけません (kucha ikemasen)

Q: Because I have a meeting, I must prepare.
ROM: Kaigi ga aru node, junbi shinakucha ikemasen.
JP: かいぎ が ある ので、じゅんびしなくちゃいけません。

Q: I have to study a lot because there will be an exam next week.
ROM: Raishuu tesuto ga aru kara takusan benkyou shinakucha ikemasen.
JP: らいしゅう テストが ある から たくさん べんきょうしなくちゃいけません。

DIR: EN>JP
Q: I had to get up at six this morning.
ROM: Kesa rokuji ni okinakucha ikemasen deshita.
JP: けさ ろくじに おきなくちゃいけませんでした。
HINT: past obligation → くちゃいけませんでした (kucha ikemasen deshita) · okiru → okinai → drop い → おきな + くちゃいけませんでした · けさ (kesa) = this morning

DIR: EN>JP
Q: (The truth is) I must practise every day.
ROM: Mainichi renshuu shinakucha ikenai n desu.
JP: まいにち れんしゅうしなくちゃいけないんです。
HINT: casual form + んです (n desu) = adds explanatory nuance · なくちゃいけない (nakucha ikenai) = casual must · + んです = "the thing is, I have to…"
