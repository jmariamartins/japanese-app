# TOPIC: It Looks Like… — 〜そうです (appearance)
# LEVEL: intermediate

# ─────────────────────────────────────────
# Structure (adjective + そうです = "looks / seems"):
#   い-adjective: drop い + そう      おいしい → おいしそう
#   な-adjective: drop な + そう      元気な → 元気そう
#   いい → よさそう (irregular)
#   Negative: ない → なさ + そう      難しくない → 難しくなさそう
#                                    上手じゃない → 上手じゃなさそう
#                                    よくない → よくなさそう
# そう then conjugates like a な-adjective:
#   そうです / そうじゃないです / そうでした / そうじゃなかったです / そうで
# Before a noun: そうな       暖かそうなセーター
# Verb stem + そうです = about to happen (imminent)
#   雨が降りそうです。 Negative: 降りそうもありません。
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: This apple looks delicious.
ROM: Kono ringo wa oishisou desu.
JP: このりんごはおいしそうです。
HINT: い-adjective: おいしい (oishii) → drop い + そう = おいしそう (oishisou) + です (desu) · りんご (ringo) = apple
