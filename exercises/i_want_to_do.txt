# TOPIC: I Want To… — 〜たいです / 〜たがっています
# LEVEL: beginner

# ─────────────────────────────────────────
# PERSONAL DESIRE (1st person only):
#   verb STEM + たいです            = I want to…
#   verb STEM + たくありません       = I don't want to…
#   verb STEM + たかったです         = I wanted to… (past)
#   verb STEM + たくありませんでした  = I didn't want to… (past)
#
# QUOTING SOMEONE'S DESIRE (3rd person, reported speech):
#   verb STEM + たい + と言っていました    = [they] said they want to…
#   verb STEM + たくない + と言っていました = [they] said they don't want to…
#
# OBSERVING SOMEONE'S DESIRE (3rd person, visible signs):
#   verb STEM + たがっています          = (it seems) [they] want to…
#   verb STEM + たがっていません         = (it seems) [they] don't want to…
#   verb STEM + たがっていました         = (it seemed) [they] wanted to…
#   verb STEM + たがっていませんでした    = (it seemed) [they] didn't want to…
#
# Key rules:
#   · たい = 1st person only (your OWN desires)
#   · たがっている = 3rd person observation (you are OBSERVING someone else)
#   · Quotation uses たい (the other person's own words)
#   · With たがっている, を is retained; with たい, が or を both work
# ─────────────────────────────────────────
