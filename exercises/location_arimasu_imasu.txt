# TOPIC: Location — There is a… (あります / います)
# LEVEL: beginner

---
DIR: EN>JP
Q: There are flowers on the table.
ROM: Tsukue no ue ni hana ga arimasu.
JP: つくえ の うえ に はな が あります。
HINT: non-living thing → あります (arimasu) · つくえ (tsukue) = table · うえ (ue) = on top · に (ni) = location particle
