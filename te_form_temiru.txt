# TOPIC: Te-form — Trying Something (〜てみる)
# LEVEL: intermediate
# SOURCE: NHK World Easy Japanese (Lessons 13, 14)

# ─────────────────────────────────────────
# Structures covered:
#   [verb-te] + みます           = I'll try doing... (present/future)
#   [verb-te] + みたいです       = I want to try doing...
#   [verb-te] + みました         = I tried doing... (past)
#   [verb-te] + みませんでした   = I didn't try doing... (past negative)
# Key rule: て-form of verb + みる (to see/try) = to try doing
# ─────────────────────────────────────────

---
DIR: EN>JP
Q: I want to try going to Japan.
ROM: Nihon e itte mitai desu.
JP: にほんへ いってみたいです。
HINT: iku → itte (te-form) + みたいです (mitai desu) · NHK Lesson 13 key phrase · へ (e) = destination direction
